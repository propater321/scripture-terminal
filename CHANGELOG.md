# Changelog

## 0.1.0 — initial source release

- Native Bun/OpenTUI study workspace with Read, Explore, Topics, Atlas, comparison and bookmarks.
- Optional Torah, both Talmuds, Mishnah, 15 Midrash collections, available Soncino Zohar and Shulchan Aruch imports, with native references and explicit language gaps.
- Local keyword and semantic search; optional reranking and cited Ask through the user's Codex login.
- Pinned and validated source imports, an MIT code license with separate data notices, source-only packaging, setup diagnostics and Linux CI.

Known limits: Zohar is English-only in the selected licensed export and has no mapped cross-references; other editions have partial language coverage. Ask is opt-in and depends on an experimental Codex app-server tool interface. Linux is the validated platform. No cross-library question, morphology engine, geographic map, or authoritative religious ruling service is provided.
